# 🧊 바탕화면 냉장고

바탕화면 한쪽에 작게(200×500) 떠 있는 냉장고 위젯이에요. 배경은 투명하고, 문을 누르면 열리면서 안에 뭐가 들었는지 태그로 보여 줘요.

<img src="assets/icon.png" width="96" alt="냉장고 아이콘">

## 기능

| | |
|---|---|
| **냉장실 4칸** | 1단 · 2단 · 3단 야채실 · 4단 신선실 |
| **냉동실 3칸** | 냉동 1·2·3칸 |
| **2중문** | 냉장실 문과 냉동실 문을 따로 열고 닫아요 (3D로 열리는 애니메이션) |
| **재료 태그** | 이름만 작게. 유통기한이 가까울수록 색이 **회색 → 모래색 → 살구 → 빨강**으로 변하고, 지나면 진한 적갈색 (날짜는 마우스를 올리면 보여요) |
| **추가 / 수정 / 삭제** | 칸마다 `+`, 태그를 누르면 수정, `×`는 빼기 (4초 동안 되돌리기 가능) |
| **꾸미기 창** | 이미지 스티커(불러오기·끌어다 놓기·붙여넣기), 이모지/글자 스티커, 낙서(펜·지우개·되돌리기), 문/손잡이 색 바꾸기 |
| **레시피 창** | 냉장고 재료를 조합해서 만들 수 있는 요리 추천. 유통기한 임박 재료를 쓰는 요리가 위로 올라와요 |

## 실행하기

[Node.js](https://nodejs.org) (18 이상)가 필요해요.

```bash
npm install
npm start
```

### 설치 파일 만들기 (Windows)

```bash
npm run dist:win      # dist/ 폴더에 설치 파일과 portable exe가 생겨요
```

macOS는 `npm run dist:mac`을 쓰면 돼요.

## 사용법

- **옮기기**: 냉장고 위쪽의 얇은 바를 잡고 끌어요 (마우스를 올리면 진하게 보여요)
- **문 열기**: 문을 클릭 → **닫기**: 안쪽 빈 곳을 클릭하거나 `Esc`
- **재료 넣기**: 위쪽 바의 `+`, 또는 칸에 마우스를 올리면 나오는 `+`
  - 이름에 `우유, 계란, 두부`처럼 쉼표로 여러 개를 한 번에 넣을 수 있어요
  - `+3일`, `+7일`, `+2주` 버튼으로 유통기한을 빠르게 넣어요
- **메뉴**: 오른쪽 클릭 또는 `⋯` → 꾸미기, 레시피, 항상 위에 표시, 자동 실행, 종료
- 기한이 3일 이내인 재료가 있으면 닫힌 문 왼쪽 아래에 작은 빨간 점과 개수가 떠요
- 위쪽 바는 마우스를 올렸을 때만 보여요

### 꾸미기 창

- **선택 도구**: 스티커를 끌어서 옮기고, 오른쪽 아래 점으로 크기, 위쪽 점으로 회전, 마우스 휠로도 크기를 바꿔요 (`Shift`+휠은 회전). 새 스티커는 마지막으로 누른 문에 붙어요
- 스티커를 다른 문 위에 놓으면 그 문으로 옮겨 붙어요
- **펜 / 지우개**: 문 위에 자유롭게 낙서. `Ctrl+Z`로 되돌리기
- 바뀐 내용은 바로 바탕화면 냉장고에 반영돼요

### 레시피 창

- 위쪽 “내 재료”를 누르면 **그 재료를 꼭 쓰는 요리만** 보여 줘요 (여러 개 고르면 모두 쓰는 요리)
- “밥·기본양념은 있다고 치기”를 끄면 밥도 냉장고에 있어야 인정돼요
- 레시피는 `src/renderer/recipes-data.js`에 있어서 직접 추가할 수 있어요

## 데이터 저장 위치

모든 내용은 한 파일에 저장돼요.

- Windows: `%APPDATA%\desktop-fridge\fridge-data.json`
- macOS: `~/Library/Application Support/desktop-fridge/fridge-data.json`
- Linux: `~/.config/desktop-fridge/fridge-data.json`

## 알아 두면 좋은 점

- 이 위젯은 “항상 위”가 아닌 보통 창으로 떠 있어서, 다른 창을 열면 그 뒤로 숨어요. 늘 보이게 하려면 메뉴에서 **항상 위에 표시**를 켜세요.
- Windows에서 `Win + D`(바탕화면 보기)를 누르면 다른 창처럼 같이 숨겨질 수 있어요. 작업 표시줄 트레이 아이콘을 누르면 다시 나타나요.
- Electron 없이 화면만 보고 싶으면 `npm run preview` 후 브라우저로 `http://localhost:5178` (이때는 브라우저 저장소를 써요).

## 파일 구성

```
src/
  main.js               메인 프로세스 (투명 창, 트레이, 저장)
  preload.js            화면 ↔ 메인 연결
  renderer/
    base.css            글꼴(Pretendard)과 공통 색
    common.js           칸 정의, 유통기한 색 계산
    fonts/              Pretendard (SIL OFL 1.1)
    fridge.*            냉장고 위젯
    deco.*              꾸미기 창
    recipes.*           레시피 창
    recipes-data.js     레시피 / 재료 별칭 데이터
tools/
  make-icon.js          아이콘 생성
  preview-server.js     브라우저 미리보기 서버
```
